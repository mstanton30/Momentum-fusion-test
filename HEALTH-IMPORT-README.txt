Momentum Fusion v9 — Screenshot-assisted health import test build

Upload index.html to the Momentum-fusion-test repository, NOT the production repository.

New: Home > Import health screenshot; Progress > Import screenshot.
Choose a screenshot for local preview, select source and measurement type, manually enter visible values, confirm, and save. The static GitHub Pages prototype does NOT automatically extract text from screenshots or upload screenshot images. Only confirmed values are stored in browser localStorage.

Workout imports count toward training minutes, activity and points; a matching workout name/date/duration is blocked as a possible duplicate. Weight imports update the Progress weigh-in records. Recovery metrics are saved as reviewed imports, but not yet used for readiness coaching. Imported entries can be removed from the import screen.

Important: Health data in this prototype is stored only on the current device/browser. Avoid using personal medical data on a public/shared device.
