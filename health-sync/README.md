# Apple Health sync in Momentum Fusion Beta

For weekly scale readings, use **Progress → Body composition → Scan scale photo** and upload the RENPHO results image. Review the readings before saving.

Momentum can still display previously uploaded Apple Health readings after sign-in. Existing Shortcut connections can be revoked in **AI connections → Connected apps and devices**. The [Shortcut specification](SHORTCUT_SPEC.md) documents the legacy upload format.
